# 安装 DSH Control

先准备 Node.js 24+（含 npm）。Windows 安装 Node.js 时无需勾选额外开发工具。

| 平台 | 下载文件 | 如何安装 |
|---|---|---|
| Windows 11 | `dsh-control-windows.zip` | 将整个 ZIP 完整解压到普通文件夹，再双击 `Install DSH Control.cmd`。不要在 WinRAR 或压缩包预览中直接运行。 |
| macOS | `dsh-control-macos.zip` | 完整解压后，双击 `Install DSH Control.command`；或在解压目录运行 `sh install.sh`。 |
| Linux / WSL Ubuntu | `dsh-control-linux.zip` | 在 Linux / Ubuntu 内完整解压，进入解压目录运行 `sh install.sh`。 |

三个包均需联网下载运行依赖。若下载受限，请使用可用的代理。

安装完成后重新打开对应系统的终端，运行 `dsh-control`。首次使用按界面提示操作。
